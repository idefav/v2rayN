# V7 紧凑连接首页

2026-11-13。由 Local Codex V7 原型落地，仅调整连接界面及反馈呈现。保留独立设置窗口、右侧选服抽屉、菜单栏、授权和已有网络生命周期行为。

## 布局

- 删除首页 ScrollViewer，使用有界 Grid；默认新窗口由 440×620 缩短为 440×560，已有窗口尺寸仍按原规则恢复，最小支持 360×480。
- 原生顶栏保留 56 点，避开 macOS 窗口按钮。高度不足 560 时切换紧凑行距，抽屉展开不会改变连接列排版。
- 节点显示最多两行，点击名称或 Tab/Enter 打开完整名称及选择/实际连接说明。名称可访问标签和悬停文本均不截断。
- 主操作固定 44 点。原有待应用、实际节点、应用更改、错误摘要、重试及诊断保留在独立的 24 点行中，不叠加增长页面高度。
- TUN 始终区分选择与实际模式；速率开关、关闭/待数据说明保留。收到数据才显示速率，避免读数与说明重叠。路由保留完整可访问名称及跳转。
- 移除底部 116 点保留区，改为 32 点单行反馈。完整阶段和错误在显式打开的详情中阅读。首页没有滚动容器；选服、设置和详情阅读区仍可独立滚动。

## 反馈行为

复用 V6 的操作标识、400 毫秒防闪、成功/取消/失败自动收起期限、后台静默、实际模式配色及取消能力。新提示不抢焦点、不打开新顶层窗口。打开详情暂停自动收起；关闭提示只隐藏，不取消生命周期操作。新操作、隐藏窗口和释放视图会关闭过期详情。
