# UI 与出口检测测试版

此版本包含 Avalonia 主窗口、服务器、分组与订阅、设置和编辑器换新。Windows WPF 保留原有界面。

## 使用

- 在服务器页添加、编辑并激活普通节点。当前代理页展示该节点及最近出口结果。
- 自动切换通过“添加服务器 → 策略组”配置成员与策略，再激活策略组。当前代理页解释策略；只有手动选择组提供成员切换。
- 工具栏分组筛选是服务器分类，不是策略组。详情、编辑位于固定行操作列或右键菜单。
- 出口地区默认显示，完整 IP 可在表格设置中开启，也可在详情复制。测试下拉菜单提供选中、分组和全部服务器的出口检测及取消。
- 自动出口检测默认开启，可在设置中关闭。新增或连接配置变化后排队检测；成功缓存 24 小时，仅活动节点过期后自动刷新。失败冷却 30 分钟，并发最多 2 个。

检测使用目标节点的独立临时代理，不切换活动服务器、不修改系统代理、TUN 或路由，也不会在失败时退回直连查询。不能安全生成独立配置的节点显示不支持。默认查询 IP.SB，也可使用现有 IP 查询服务配置。

地区由查询服务提供，显示的是最近一次观察到的出口；多出口节点可能变化。查询会向配置的查询服务发送网络请求。失败保留并标识旧成功结果，不能当作实时结果。

## 验证范围

本地 ServiceLib 156 项测试通过，包含隔离 SOCKS 路径、IPv4/IPv6、限流、取消、配置指纹和独立路由配置。三个 Avalonia RID Release 发布成功，Linux X11 隔离原生检查通过。UI 验证使用隔离数据，不改变正在使用的客户端及系统代理。

本轮 macOS／Windows 原生运行、Wayland、真实公共查询服务及长期自动队列仍待验收。GitHub 工作流执行跨平台构建、隔离 SSH 测试及包完整性检查；应以对应 Actions 的最终状态为准。包为测试版本，macOS 未进行开发者签名及公证。
