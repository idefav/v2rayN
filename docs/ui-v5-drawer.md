# V5 连接窗口：右侧选服与彩色菜单栏

本轮延续 V4 的独立连接窗口和设置窗口。设计先由 Local Codex 在现有项目中生成 V5，再将右侧选择、按钮状态和菜单栏状态标识落到 Avalonia。保留旧管理功能、授权、退出与内核生命周期行为。

## 连接窗口

- 默认 440×620；选服向右增加 350 点，连接区保持原宽。窗口右侧空间不足时仅平移必要距离，按当前屏幕工作区和缩放计算。
- 展开／收起 280 毫秒，从当前显示进度反向；重复点击不排队。列表独立滚动，管理入口固定在底部。关闭恢复原尺寸和位置，退出保存收起尺寸。
- 原生回归发现窗口动画的像素取整会让 Grid 向连接区分配额外 0.5 点；展开期间直接固定连接滚动区宽度，动画过程和结束均检查内容位置与尺寸不变。
- 空间不足或不可调整大小时，同窗口显示可返回的选择页面。macOS 的“减少动态效果”直接完成布局。
- 选服保留搜索、常用、完整身份信息、延迟和管理入口；所选与实际正在使用单独标记。打开、搜索、收起不触发重连。
- 搜索获得焦点，Esc 可返回。动画结束不得从授权弹窗或独立设置窗口抢走键盘焦点。
- 主按钮使用一个完整 ContentPresenter 表面，显式定义浅深色的正常、悬停、按下、焦点和禁用状态。避免 Semi 模板在主按钮上叠加另一块灰色背景。

## macOS 菜单栏

修复前，隔离程序实际读取的 AppKit 按钮为 22×22 点，图像为 40×17 点。原后端使用方形状态栏槽位，宽图超出了按钮区域。新的图像采用 18×18 逻辑点，实际原生缩放后为 17×17。

用户追加彩色要求后，改为两个独立的 P/T 圆角状态块。P 是系统代理，T 是实际 TUN：

| 状态 | P | T |
|---|---|---|
| 已确认开启 | 蓝色 `#126CE5` 实心 | 绿色 `#0D8057` 实心 |
| 已确认关闭 | 灰色空心 | 灰色空心 |
| 未确认 | 橙色 `#9D5B10`，带问号 | 橙色 `#9D5B10`，带问号 |

关闭态浅色菜单使用 `#596579`，深色菜单使用 `#B7C1D1`。颜色由系统外观决定，不跟随应用强制主题。开启和未确认状态保留白色字母，未知另有问号；不只依赖颜色。macOS `IsTemplateIcon=false`，避免 AppKit 抹掉状态颜色。下拉菜单及全部快捷操作继续复用原动作。

原生状态依据仍为内核健康结果和只读系统代理查询；用户选择某个模式不会直接把运行图标标为已开启。

## 验证入口与边界

`v2rayN.Desktop.Review --workspace-v5-only` 覆盖实际控件布局、快速反向、搜索/常用空态、焦点、授权交错、窄屏、隐藏窗口、屏幕边界、按钮模板和 PNG 像素、36 组图标资源。`--startup-only` 实例化生产启动路径；macOS 下直接读取测试进程自己的 AppKit 状态栏按钮尺寸、可见性和图像。V5 原生检查还读取 AppKit 图像中的彩色像素，确认未被模板染色。

回归只使用隔离数据。未启动真实内核、未操作本机 TUN、系统代理或路由。Windows/Linux 原生窗口和真实 VoiceOver/输入法面板没有在本机验收；CI 配置新增相应 V5 检查，本次没有推送触发远端运行。

2026-11-13 最终 macOS ARM64 原生连续回归：V5 162 项、V4 78 项、生产启动路径 12 项全部通过。V5 的实际 AppKit 图像为 17×17 点，处于 22×22 点可见按钮内，`Template=false`，彩色像素存在；最后代码的 V5 Headless 回归为 160 项。

## 默认定位已选服务器（2026-11-13）

每次打开“更换服务器”均清空上次搜索并显示全部节点；数据加载和抽屉展开完成后，根据真实布局将配置中已选择的节点滚动至可视区域中间，并以蓝色边框、浅色底及“已选中”文字标记。定位依据是所选节点，不是运行快照中的旧节点。搜索框保留键盘焦点，不触发节点选择或连接动作。

定位只执行一次，随后手动滚动、搜索或使用常用筛选不会被拉回。关闭时丢弃待定位目标；没有有效选择时从列表顶部展示。异步 `TextChanged` 的重复通知不会重新生成相同筛选结果，以免丢失滚动位置。

追加真实控件回归：80 个隔离节点中的第 70 项自动显示、过期搜索和常用筛选、搜索焦点、手动滚动、重新打开、无动画、窄窗口、选择改变、节点缺失，以及整个过程不启动内核。最终 macOS 原生 174 项、Headless 172 项通过；截图直接断言目标行完整位于实际 ScrollViewer 可视区域，而非仅检查内部状态。
