# V6 原位连接反馈

设计由 Local Codex 在保留 V5 的基础上完成，入口为 `v2rayn-connection-prototype-v6.html`。本轮改进连接反馈和状态颜色，保留独立设置窗、选服抽屉、菜单栏及原有管理功能。

## 反馈行为

- 普通连接、断开、切换和系统代理更新不再打开独立进度窗口。连接窗底部保留一条反馈区；设置窗使用右下角小提示，不挤压表单和保存按钮。授权继续使用原有模态确认。
- 进度延迟 400 毫秒显示；短操作直接显示结果。成功、取消、失败分别在 3、4、8 秒后自动收起；鼠标悬停或键盘焦点在提示内时暂停。
- 关闭提示仅隐藏，不取消操作。同一操作的后续阶段不再次弹出。连接主页可显式回看最近进度。用户打开进度时将键盘焦点放到阶段按钮，普通进度更新不移动焦点。
- 同一操作只更新原位内容，使用单调操作标识拒绝过期阶段和重复终态。旧计时不能关闭新操作。自动恢复静默更新；应用隐藏时不唤起窗口，也不在返回时重放成功提示。
- 连接及模式切换保留既有取消路径。断开清理和系统代理更新不提供取消，以免暗示不存在的能力。停止和权限逻辑不变。
- 失败提示收起后，主页错误摘要、重试和诊断仍保留。系统代理完成明确显示“系统代理已更新”，不宣称内核连接成功。端口等待只来自真实等待阶段，显示实际秒数，不伪造百分比。

## 颜色与布局

状态标题改为紧凑的左对齐布局，实际运行模式单独显示。主按钮普通模式蓝色 `#126CE5`、实际 TUN 绿色 `#0D8057`、切换中琥珀色 `#9D5B10`；与菜单栏 P/T 配色保持一致。所选 TUN 开关不决定运行颜色。

按钮保持完整单一表面，悬停、按下、禁用不改变尺寸；等待时白字白图标，覆盖主题禁用文字色。实际模式与用户选择继续分别显示。提示采用实色表面、短淡入和文字阶段，支持 macOS 减少动态效果。

两个原生窗口各自持有视图，共享一个反馈状态与单调时钟。避免将活动控件在不同 LayoutManager 之间移动。设置提示浮在内容上方，空闲时不占用表单高度；连接主页保留稳定的反馈槽。

## 设计参考

- [Apple Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts)：常规操作反馈避免不必要打断。
- [Apple Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback)：状态反馈就近呈现，文字与图形配合。
- [Microsoft InfoBar](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/infobar)：原位非阻塞反馈，避免重复闪烁。

计时与预留空间为本项目设计选择，不是官方规定。没有安装、替换或重启当前客户端，没有操作本机 TUN、代理、路由和用户配置。
