# V3 连接主页与分组设置

本地桌面实现依据已确认的 Local Codex V3 原型。主页取消侧栏，仅展示连接状态、所选节点、连接/断开、TUN、实时速度及开关、路由摘要；完整管理功能仍使用原来的视图和命令。

## 入口映射

| 原入口 | V3 入口 |
| --- | --- |
| 服务器列表、导入、协议编辑、分享、测速 | 首页“更换服务器” → “管理服务器”，或设置 → 服务器与订阅 → 服务器管理 |
| 分组、订阅与订阅更新 | 设置 → 服务器与订阅 → 分组与订阅 |
| 当前代理、策略组 | 设置 → 服务器与订阅 → 当前代理 / 策略组 |
| 连接控制中的系统代理模式 | 设置 → 网络与路由 → 系统代理，标注即时生效 |
| 本地监听、检测及重启服务 | 设置 → 网络与路由 → 连接基础与监听 |
| TUN 开关 | 连接首页；高级配置位于设置 → 网络与路由 → TUN |
| 路由选择、编辑、导入 | 首页路由摘要，或设置 → 网络与路由 → 路由规则 |
| DNS、出口与逐节点设置 | 设置 → 网络与路由 → DNS 与流量出口 |
| 当前连接、代理检查、日志 | 设置 → 诊断与状态对应页面 |
| 应用选项、外观语言、更新、资源来源、备份、工具、帮助 | 设置 → 应用对应页面 |
| 默认内核、完整模板 | 设置 → 高级对应页面 |
| Windows 全局快捷键 | 设置 → 应用 → 快捷键；非 Windows 不展示 |

设置导航支持功能关键词搜索，与服务器搜索分开。页面仍在同一个窗口内；内容区不再嵌套完整侧栏。TUN 高级选项使用横向分节导航。

## 状态与编辑规则

- 保存设置与启动连接分开；首页显示待应用状态。断开时更换节点、切换 TUN 或后台资源更新不会自动建立连接。
- 主按钮断开时清理系统代理和当前主/前置内核，保留配置选择；清理尚未确认时显示继续确认退出。
- 切换窗口消费生产生命周期事件，显示准备、停止、必要时等待端口、启动、验证和结果。普通切换不展示 TUN 专属等待；取消不等于恢复原模式。
- 系统代理更新有独立结果，不冒称已建立内核连接。
- 进入设置不改变连接。离开未保存的编辑页时提供保存、放弃、继续编辑。外观只预览，保存才持久化；放弃恢复已保存外观。
- 干净编辑页重新进入时读取最新配置，防止用旧草稿覆盖首页开关。设置中 Command/Ctrl-S 保存当前编辑页，不触发旧版截图导入快捷键。
- 更新开始时记录连接意图；断开时仅安装内核，下载期间断开、换配置或退出后不再自动重连。已运行连接的更新失败仍会回滚。
- 设置页保留首页状态订阅，但隐藏控件不参与键盘焦点；回到首页恢复操作。F5 在策略组页刷新该页，只在连接首页执行重启。
- 设置导航在跳转后自动滚动到当前菜单项；重复进入当前页面也会恢复菜单定位，不重建内容。长标题在窄窗口与大字号下换行显示，并保留完整提示。
- 新增原型中的 47 个矢量图标，使用主题颜色和可访问名称；常用服务器作为可选偏好保存。

## 隔离验证

`v2rayN.Desktop.Review --workspace-v3-only` 使用可丢弃数据库、禁止内核启动、禁止系统代理与自启动项写入；分别支持 Avalonia Headless + Skia 和原生 macOS 窗口。覆盖全部当前平台设置页、搜索、草稿导航、外观恢复、常用节点、空节点、切换取消/重试、界面心跳及宽窄/浅深色布局。

新增回归覆盖更新时的断开意图、生命周期锁内重检、设置页 Tab/Shift-Tab 焦点和 F5 路由，以及 800px 窗口、14/24px 字号下的菜单定位和完整文字边界。原有完整 UI 与 `--primer-only` 检查已迁移到设置中的日志、关于、监听和路由入口。`--verify-failure-exit` 会故意触发一次检查失败，预期进程退出码为 1，用于保证异步关闭不会把 CI 失败覆盖成成功。

初版交付见工作区 `artifacts/local-workspace-v3-20261112/VERIFICATION.md`；本轮功能修复与回归结果见 `artifacts/local-workspace-v3-fixes-20261112/VERIFICATION.md`。不包含安装、GitHub 提交或发布。

原生窗口补验及后续导航修复见 `artifacts/local-workspace-v3-native-20261112/VERIFICATION.md`，包含最终代码的原生 V3、完整管理、中英文浅深色和 800px 窗口结果。

## 与旧版功能对照

新增 `--workspace-parity-only` 可单独运行旧入口对照回归，也包含在 V3 全量回归中：

- 旧“添加/导入服务器”菜单逐项对应到服务器管理的两个菜单，核对协议、剪贴板、屏幕与图片导入的原命令绑定。
- 服务器右键菜单保留编辑、复制、删除、去重、清除无效结果、TCP/真实连接/下载/UDP 检测、排序、移动、分享、五种导出及策略组生成。
- 分组与订阅保留全部/选中及通过代理更新；路由保留默认选择、规则编辑、导入及域名策略；日志保留筛选、复制、清理、自动刷新与自动滚动。
- 更新保留仅检查、检查并更新、代理开关、预发布和来源入口；备份保留本地与 WebDAV；原系统工具和帮助操作仍通过原命令/事件执行。
- 窄窗口展开运行详情时，详情区域独立滚动，设置编辑区和保存按钮仍可用；设置关键词支持中英文和多词查找。
- 设置分组标题在大字号、窄窗口下完整换行，保留完整提示和可访问名称；回归检查实际文字排版宽高，防止标题被裁切。
- 当前连接 API 不可用时暂停会话操作，已有列表明确标为上次快照；可用状态变化后原位刷新文案和按钮状态。
- 关于页保留版本、操作系统、CPU 架构和 .NET 运行时信息。

完整菜单和表单入口的源码对照、隔离测试结果及本轮范围见工作区 `artifacts/local-workspace-v3-parity-20261112/VERIFICATION.md`。对照测试不会执行网络检测、订阅下载、恢复数据或系统工具命令，不将入口覆盖等同于真实网络验收。
