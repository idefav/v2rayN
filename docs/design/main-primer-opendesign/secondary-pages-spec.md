# v2rayN 次级页面统一设计与交接规范

版本：01 · 2026-10-25。设计入口：[page-designs.html](page-designs.html)。无需依赖，可直接双击打开。覆盖清单：[coverage.md](coverage.md) / [coverage.json](coverage.json)。

## 本次交付范围

沿用已确认的 GitHub / Primer 设计系统，补齐9个页面族、27个目录路由、13种协议字段变体。原 `index.html` 的节点表格、运行/选中区分、详情、连接控制、主题、双语、日志抽屉和多协议检查保持不变；原32项测试与两份规范未改写或删除。

次级原型是独立文档，不与主页面共享实际业务状态。手动策略组切换、保存设置、关闭演示连接等操作均不改变主页面运行节点。返回主页面使用导航底部链接。

所有地址、节点、版本、速率、时间、指纹和公钥均为虚构演示。页面不读取本机文件、用户配置或凭证，不请求代理、订阅、WebDAV、更新站点，不运行命令，不安装、下载、备份、关闭真实连接或修改系统。

第一段 `:root` 与原主页面 token 完全一致，回归脚本验证两者相等。深色沿用原型现有的 Primer 语义映射，不创建第二套品牌色。

## 页面族动作与字段

### 分组 / 订阅

列表包含名称/来源、节点数、上次更新时间、启用、更新频率、状态和操作。选中集合与启用状态分离；更新选中只处理勾选且启用的项目，更新全部处理全部启用项目。直连/代理路径是本次更新的显式范围，并在确认与任务摘要中展示。

表单包含名称、虚构HTTPS URL、小时更新间隔（0为手动）、过滤文本、前置获取路径、后置节点应用策略。后置默认保留活动节点，不自动应用新节点。过滤文本只是字段演示，不执行用户代码或完整表达式。

任务状态 `Idle → Busy → Done | Error | Cancelled`，更新中禁止同类重入。失败保留节点数与原数据，标记更新失败后可重试；删除单独确认对象及节点数量，不偷偷切换运行节点。

### 代理策略与代理链

- 单节点：显示协议、端点、接口能力，不伪造自动组决策。
- 手动组：候选中的切换按钮只改变该演示组；主界面运行状态不变。
- 自动延迟：评估间隔与容差，候选没有“已选择”或手动切换按钮。
- 故障转移：候选顺序代表优先级，不是串联连接。
- API不可用：当前决策未知，禁用手动切换，不根据配置推断已运行结果。
- 串联链：独立的有序节点集合，逐跳预览；失败停止或报告，不默默跳过中间跳。

策略组和链共用筛选/多选节点选择器，选择在弹窗内暂存，取消不提交。当前集合计数包括筛选隐藏项。确认修改的只是编辑集合，不是活动节点。

### 连接

目标、网络/类型、链、进程、时长、流量完整展示；文本与网络筛选、演示自动刷新、右侧详情抽屉可操作。关闭单条列明目标；关闭全部包含筛选隐藏项，列明完整集合数量。取消保持列表，失败保留连接，确认仅移除原型行。

### 路由

规则集列表有启用、默认、顺序、默认出站及添加/内置导入/移动/删除。每个规则集独立保存规则集合。规则集编辑支持可视化与JSON；单条规则有域名、IP/CIDR、端口/区间、进程、出站和启用状态。单条非空条件为AND，规则按顺序首条命中。

移序和删除进入草稿；放弃恢复进入页面或上次保存时的集合。保存规则集JSON要求对象根及rules数组；不声明真正的路由匹配引擎语义已验证。内置导入只替换演示草稿，不读取文件。

### DNS、模板、自定义配置

基础、直连、远程、TUN职责明确；上游URL/主机与目标/引导地址分开。Xray和sing-box提供对应形式的JSON样例；TUN等能力有显式提示，不直接套用另一个内核的字段。

JSON组件区分四种对象：DNS配置、未来完整配置模板、完整自定义配置、单个自定义出站。标题始终说明生效范围；不得用代理检查的出口结果充当DNS配置。

格式化只改变合法JSON的排版；语法失败显示行/列并定位选择。校验范围是语法和对象根，不是内核版本级语义。默认配置导入需确认覆盖草稿。表单与JSON为独立演示草稿，不自动互转。

SSH获取演示指纹后仍未可信；人工核对端点/指纹并确认才固定。主机或端口改变即失效，取消正在进行的测试，禁止迟到回调恢复信任。TCP/SSH分阶段演示不证明UDP/HTTP3扩展可用。

### SSH公钥部署

目标确认 → 端点/指纹人工核对 → 本地演示密钥引用 → authorized_keys追加公钥预览 → 模拟部署/新连接验证 → 结果/恢复。

目标选择只允许一个SSH节点。确认门槛不可跳过；切换目标需重新核对。只展示演示公钥与指纹，不读取或展示私钥。部署失败提供回到授权预览和重试，说明保留旧认证入口、只检查本次追加条目；不执行回滚命令或远程授权。

### 设置、备份、更新

五节设置均使用固定保存条。核心：内核、端口、API、超时、能力项。应用：主题、字号样例、语言与托盘；真实客户端语言需重启，原型顶部即时双语预览。Windows可配置演示全局快捷键，macOS/Linux显示不可用。系统代理：模式、类型、绕过/PAC。TUN：栈、MTU、DNS、路由、排除、权限依赖。内核管理：接口、遮盖令牌、超时、检查/重启范围。

备份分本地/WebDAV，账户和密码遮盖，不保存输入。恢复必须先载入元数据、再校验、再确认覆盖；确认列出节点/订阅/路由/DNS/偏好和私钥/密码/API/WebDAV凭证排除项。不是合并，不自动应用运行节点。生成/导出只打开文本预览，不写备份文件。

客户端与内核更新使用独立检查和下载任务；展示当前/可用演示版本、平台架构、进度、失败重试。下载完成只表示流程演示结束，没有实际文件，不提供“安装成功”或真实安装动作。

### 完整日志与组件画廊

日志与原抽屉共用细边框、12px等宽行和语义级别；数据隔离。支持级别/文本、暂停、跟随、追加演示事件、复制、清空范围确认、导出预览、错误详情和空态。

画廊可打开删除、未保存三选项、主机固定、分享范围确认、sudo用途输入、Toast/内联错误/进度/空态/禁用。分享默认遮盖身份，展开或复制先确认范围。二维码仅编码固定虚构链接，本地Version3-L字节模式与RS校验，无物理扫码承诺。sudo输入遮盖且立即清空，取消作废后续回调；未执行真实权限请求。

## 状态与提交边界

| 状态 | 行为 |
|---|---|
| 正常 | 可浏览与编辑；明确演示标签 |
| 空集合 / 未载入草稿 | 有加载演示默认值或添加入口，隐藏无对象的保存条 |
| 忙碌 | 禁止重入；主体预览忙态禁用输入与提交，顶部状态预览仍可返回正常 |
| 失败 | 保留旧数据与草稿；内联错误/任务状态与重试入口，不伪造成功 |
| 能力不可用 | 显示具体能力边界，策略/接口/平台相关动作禁用 |
| Dirty | 目录和子页导航拦截为保存/放弃/继续；非法保存不离开 |
| 取消 | 终止该任务令牌，未执行阶段不判成功 |

保存时捕获草稿，只在模拟成功后提交；失败保持Dirty。策略候选、串联顺序与规则草稿的放弃会恢复快照，不只是隐藏提示。不同对象的数据不可只因共用组件而共用保存集合。

## 响应式、双语与可访问性

| 宽度 | 布局 |
|---|---|
| 1440 | 208px导航；单列工作区；分段表单内部双列；表格完整或容器内横滚 |
| ≤1000 | 64px图标导航，原生title与aria-label；目录和画廊改单列 |
| ≤800 / 760 | 表单单列，标题动作分行；步骤分成两行，每行3步 |

中文为默认，所有界面标签、提示和状态有英文分支；用户输入的数据不自动翻译。支持Tab/Shift+Tab、Enter/Space、Esc原生对话框/抽屉关闭、Ctrl/⌘+S保存。可聚焦元素有focus-visible；触控设备按钮/输入目标至少44px。关闭/失败/不可用都含文字，不只靠色彩。
