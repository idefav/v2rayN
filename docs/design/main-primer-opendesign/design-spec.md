# v2rayN 桌面主界面设计规范

交付版本：02 · 2026-10-25。本次仅修正代理检查关联页。入口：[index.html](index.html)；直达诊断演示：[运行态诊断](index.html#diagnostics/partial/zh/light)。直接双击即可在本地浏览器预览，无依赖、无网络访问。此交付是 HTML 产品原型，不是客户端实现。

## 设计目标与边界

面向 macOS / Windows / Linux 的 Avalonia 桌面代理工具。主任务是快速识别当前运行配置、查找节点、检查路径，并显式应用选中的节点。采用已绑定的 GitHub / Primer 设计系统：系统字、细边框、矩形信息分区与密集列表适合跨平台工程工具。仅使用组件基础语法，不复制仓库、Issue 等 GitHub 产品结构。

所有名称、地址、上下行速率、时间、延迟、速度、密钥和结果均为虚构演示；未读取任何真实工程、配置、节点或凭证，未启动内核或访问代理服务器。节点与观察端只允许 example.com / net / org 及其子域，或 RFC 5737 文档 IPv4；诊断 IPv6 基线另允许 `2001:db8::/32` 文档地址。无装饰图片和外部资源。

## 信息层级与首屏

- 顶栏 56px：v2rayN 品牌、演示标记、可访问的状态预览、语言与主题。状态预览属于此评审原型，生产构建不保留。
- 左栏 196px：节点、分组/订阅、代理链、路由、连接、代理检查、日志；设置和帮助靠底部。
- 内容区：页面标题 → 当前连接摘要 → 筛选和工具栏 → 节点表格及详情。
- 摘要显示运行节点、内核、系统代理、TUN、路由、上下行速率。本地端口收进连接控制对话框，避免首屏杂讯。
- 表格保留独立滚动容器；长路径详情独立滚动，底部编辑/应用操作保留可见。底栏 32px 显示内核和演示边界。
- 日志抽屉高 260px，位于内容区底部，可以关闭，不作为常驻大面板。

1440×900 是设计基准。默认 10 个演示节点，包含 SSH 直连、国内中继、香港中继、SS、VLESS。首屏允许表格内部纵向滚动，不强求同时展示十行。

`index.html` 第一个 style 中保留注入的完整 `:root` token。组件颜色只引用 token。下表是交接速查，实际定义以 HTML 为准。

|---|---|---|
| 主背景 | `--bg` | #ffffff |
| 次级背景 | `--surface` | #f6f8fa |
| 正文 | `--fg` | #1f2328 |
| 辅助文字 | `--muted` | #656d76 |
| 边框 / 内部分隔 | `--border` / `--border-soft` | #d0d7de / #d8dee4 |
| 主交互 / 悬停 | `--accent` / `--accent-hover` | #0969da / #0550ae |
| 成功 / 警告 / 错误 | `--success` / `--warn` / `--danger` | #1a7f37 / #9a6700 / #cf222e |

深色使用 Primer 深海军蓝背景的 OKLch 表达：背景 `oklch(17.7% .014 258)`、表面 `oklch(21.8% .016 257)`、正文 `oklch(94.3% .011 249)`、辅助文字 `oklch(76% .015 255)`、边框 `oklch(40% .016 258)`。蓝、绿、黄、红分别提高亮度以匹配深色对比；不在组件层添加额外调色板。设置遵循 OS 宿主可替换的语义角色。

## 组件与状态

### 节点列表

- 单击行选择详情，灰色选中底色与加粗名称；详情明确写“当前选中”。绿色圆点及“运行中”属于另一个独立状态。
- 表格复选框单独管理批量集合；点击复选框不触发行选择。表头复选框只作用于筛选结果，跨筛选的已勾选集合保留，计数始终显示全部已勾选数。
- 搜索匹配当前语言名称和地址；分组与协议同时生效。名称、延迟、速度支持双向排序；超时作为延迟排序末值。
- 更多菜单支持全选筛选结果、清空、复制详情节点地址、移除勾选节点。移除有确认层，运行节点保留。
- 演示导入入口载入内置脱敏节点；添加和编辑只允许演示地址。没有本机文件读取和订阅网络同步。
- 地区列显示“缓存 · 14:30”，详情显示缓存 IP 和“不代表当前流量出口”。测试选中只模拟 TCP 测试，不产生出口证明。

### 显式应用

`Idle → Applying → Succeeded | Failed`。应用中显示文字，锁定重入与节点选择；直到成功才更新运行节点。失败保留原节点与摘要，Toast 和日志均显示失败。顶部状态预览选择“下一次应用失败”，再按“设为活动节点”可复现完整失败流程。

### 连接控制

系统代理模式、TUN、路由先作为草稿；点击应用后模拟等待。失败回滚已应用状态，草稿留在对话框，便于重试。重启/启动内核共用应用中的防重入。混合端口与 API 端口只展示示例，不监听。此原型不模拟权限弹窗，真实 TUN 权限属于后续工程评审。

### 代理检查：按协议与路径分组的运行态诊断

检查开始时固定**当前运行的一个演示节点**，同时冻结内核、系统代理、TUN、路由、节点地址、配置版本、观察端和基线快照。列表中的详情选中、多选和地区不影响检查范围。结果不再按节点或地区分组，不遍历节点库存；主界面“测试选中”仍为独立的批量节点测速入口。

| 分组 | 固定演示项目 | 出口语义 |
|---|---|---|
| 网络接管 | 系统代理状态、TUN 接管能力 | 系统设置能力项，不是通信证明；不适用客户端出口 |
| TCP / TLS | SOCKS5 TCP CONNECT、HTTP CONNECT HTTPS/TLS、系统路径 HTTPS | 纯 TCP 建连不产生出口；HTTPS 服务端回传可产生请求对应出口 |
| DNS | 本地 DNS UDP、DNS TCP、系统 DNS 递归解析器观察 | 受控直达 DNS 可回传该采样源地址；系统递归解析器单独标注，不能比较客户端出口 |
| UDP | SOCKS5 STUN UDP、native STUN UDP | STUN 映射地址作为相应 UDP 路径的演示证据；不支持时无样本 |
| QUIC / HTTP3 | SOCKS5 HTTP3、native HTTP3 | HTTP3 服务端回传 QUIC 请求源；握手失败不能虚构出口 |
| IPv4 / IPv6 | IPv4 HTTPS、IPv6 HTTPS | 地址族独立；本演示 IPv6 明确不支持、没有采样，不代表真实节点能力 |

共14项。默认样例包含系统路径 HTTPS / native STUN 出口不符、HTTP3 通信失败、受控 DNS TCP / native HTTP3 已观测但未配置预期、递归 DNS 解析器地址、SOCKS5 UDP 与 IPv6 不支持、TUN 关闭跳过。

桌面六列：协议/目标、检查路径、通信结果、实际出口/证据、预期比较、耗时。项目名称可展开独立证据、样本ID/时间/源地址、建议及基线键。窄窗改为对应卡片，同样保留全部字段与证据展开，不要求横向查找诊断结论。状态与通信是独立字段：通信通过但出口不符的综合结论仍为失败。

| 综合结论 | 条件 | 比较栏 |
|---|---|---|
| 通过 | 能力项核对完成，或已取得同一路径客户端证据且匹配预期 | 能力项不适用；流量项符合预期 |
| 失败 | 通信失败，或通信通过但出口不符 | 证据不足 / 出口不匹配；不能用失败前缓存补齐 |
| 不支持 | 演示路径没有对应协议能力，如 IPv6 或 SOCKS5 UDP | 证据不足，0样本、无出口 |
| 无法判定 | 纯 TCP 无出口证据、递归解析器观察、已观测但未配置预期 | 不适用 / 解析器不参与比较 / 未配置预期 |
| 跳过 | 本次 TUN 关闭，能力预检决定跳过 | 无采样，不判通过 |
| 已取消 | 在执行前取消该项目 | 无采样、无出口、不计入已执行进度 |

进度分母固定14。分子只统计实际完成评估的项目；支持性预检和跳过判断可计为已评估，但取消且未执行的行 `executed=false`，例如4项后取消仍为4/14，不能因为14行都有状态就显示100%。通信成功计数排除系统能力项，出口匹配计数仅统计 `compared && match`。

基线键为 **协议 + 观察目标完整地址 + 检查路径**，IPv4 / IPv6 分别校验 RFC 5737 和 `2001:db8::/32` 文档地址。未配置预期的已观测项明确显示“未配置预期”，不计匹配；系统设置、纯 TCP 和递归 DNS 没有客户端基线入口。观察端分别配置 HTTPS、STUN、受控 DNS、HTTP3。更改观察端目标后旧目标基线不会自动复用；修改基线或观察端都会使旧结果失效。

入口保留开始、取消、重新完整检查、重试失败项、导出、基线和观察端配置。重试只重新排队综合结论为失败的项目，保留其他结果和失败项历史，继续使用原快照；不支持、未配置预期和未执行项不伪装成可恢复的通信失败。演示中重试可恢复 HTTP3 超时，但出口不匹配保留，便于检查两种失败原因。

运行检查时，如果开始模拟应用另一个节点、应用连接配置或重启内核，立即保守取消本次检查，拒绝迟到回调。即使应用最终失败，也不复用已中断的报告。已完成报告遇到成功配置变化后标记过期，保留原节点归属，不换成新运行节点名称。过期报告只能重新完整检查，不能增量重试。导出同时携带会话、运行快照、证据范围、目标/路径、执行标志、样本、历史及 `demo: true / liveValidated: false`。

## 断点与布局

| 宽度 | 策略 |
|---|---|
| ≥1191px | 196px 导航 + 主表 + 280px 详情（≥1350px 为 284px） |
| 901–1190px | 导航保留，详情为 320px 右侧覆盖抽屉，独立关闭 |
| ≤900px | 导航缩为 64px 图标轨，全部按钮有可访问名称与原生工具提示 |
| ≤650px | 搜索独占一行，筛选弹性排列，工具栏可换行；标题20px |
| 760×900 / 600×900 | 侧栏折叠，表格最小760px并在内部横滚，详情≤320px；顶部重要操作保留 |

产品最低宽度 600px。页面本身不通过裁切掩盖横向溢出；超宽表格由自己的滚动容器承担。760px 时名称、协议、分组、延迟优先可见，其他列可横滚。键盘滚动表格需要先聚焦表格滚动区域。

诊断页单独使用1000px断点：1440px为六列表格；760/600px为按协议分组的双列字段卡片，证据区域单列。操作栏自然换行、开始/取消与重试不遮挡；快照和长目标地址可以换行。主界面节点表格的原有断点、布局、选择与运行状态不变。

## 双语与无障碍

- 中文默认，可切 English；页面、对话框、状态、帮助和动态反馈均来自同一字典。用户自己输入的名称不自动翻译。节点种子中英名称分别维护。
- 本地仅持久化主题、语言；不持久化节点、演示基线或日志。切换语言关闭当前对话框，避免混合语言草稿。
- Tab / Shift+Tab 遍历；Enter 选中行；Space 勾选行；复选框自身保留原生操作。Ctrl/⌘+K 回到节点搜索。Esc 按原生 dialog 优先级关闭，然后关闭日志或详情。
- 对话框使用原生 dialog、标题关联及焦点圈定；关闭后恢复原焦点（若元素仍存在）。每个可聚焦元素都有清楚的 focus-visible。
- 窄屏详情为非模态检查抽屉，主表仍可操作；不要使用模态语义阻塞主表。关闭后焦点回当前行。
- 使用 aria-live 宣布结果；每行有 aria-selected，排序表头有 aria-sort。运行/失败/未比较均有文字，禁止仅靠颜色。
- 精密鼠标控件高36px、导航44px；触控设备自动升至44px。表格行53px、触控56px。
- prefers-reduced-motion 下禁用过渡和按压位移；异步等待仍保留，以表达真正的状态转换。
