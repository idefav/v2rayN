# Avalonia 实施记录

2026-10-25：已将本设计的主要视觉与布局应用到 Avalonia 桌面界面。HTML 原型保留用于设计参考，实际客户端显示真实配置与检查结果，不包含演示状态选择器或虚构节点。

## 已实施

- Primer 浅色与深色语义色、细边框、6px 圆角、24px 页面标题和可随用户字号调整的节点行高。
- 196px 桌面导航、900px 以下的 64px 图标导航；顶栏提供浅色、深色、跟随系统及外观/语言设置入口。
- 两层连接摘要：明确区分内核状态、活动配置、系统代理模式、TUN 和路由；应用中与配置失败有可见提示。上次出口检测明确标记为缓存。
- 节点工作区的筛选与操作分行排列，保留原有菜单、列偏好、批量操作、固定操作列和虚拟化。首次使用的默认列包含协议、分组、延迟、速度、缓存出口和状态。
- 当前选中使用中性背景，活动配置使用绿色文字标记。仅选择行不会切换节点，详情提供显式应用按钮。
- 284px 桌面详情与窄窗覆盖抽屉、固定底部动作、可滚动详情；SSH 显示端点匹配的主机密钥固定信息与扩展配置，不将配置标志宣称为网络验证成功。
- 代理检查沿用真实检测服务，保持通信、综合结论、实际出口与预期比较的独立字段；桌面六列、窄窗带字段标签的卡片，保留展开证据、基线、取消、重试和报告入口。

## 与原型的工程适配

连接控制沿用现有即时应用、错误处理和回滚逻辑，没有加入原型中的模拟草稿提交层。节点多选、双击及快捷键继续遵守现有客户端配置。语言通过现有设置修改，仍遵循重启生效提示。未重写内核、代理协议或系统接管逻辑。

相关源文件位于 `v2rayN/v2rayN.Desktop/Assets/WorkspaceStyles.axaml`、`Views/MainWindow*`、`Views/StatusBarView*`、`Views/ProfilesView*`、`Views/ServerWorkspaceView*`、`Views/ProxyCheckView*` 以及 `Common/ExitPresentation.cs`。
