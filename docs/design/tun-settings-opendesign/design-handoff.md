# v2rayN · sing-box TUN 独立设置页

交付日期：2026-10-28。入口：[交互原型](index.html)。打开本地 HTML 即可使用；CSS、JavaScript、帮助文案与图标全部内联，无外部依赖。配套视觉绑定见 [brand-spec.md](brand-spec.md)。

## 交付范围

这是供父任务移植为 **原生 Avalonia** 的网页交互原型，不作为 WebView 交付。核心流程为：配置 TUN → 查看使用说明与联动错误 → 保存并应用（模拟）。

全程仅创建当前设计项目文件；只读参考了指定的主界面设计规范。没有编辑 v2rayN 源码或真实配置，没有启动任何内核，没有发起网络请求。页面的 CSP 禁止网络连接、外部脚本、外部字体和表单提交。规则集选择文件仅取得文件名，不读取内容；远程 URL 只作为文本保存。

运行摘要固定为明确标注的**示例**：TUN 实际使用内核 `sing-box 1.14.2`、TUN 关闭、配置待启用；它不是本机检测结果。应用成功仅更新内存里的已保存快照，绝不宣称网络验证通过，绝不自动开启 TUN。内核版本号不得直接用作原生实现的最低支持版本。

## 页面结构与核心流程

1. 顶栏：v2rayN、设置、离线交互原型标记、中英切换、浅深主题。
2. 标题与紧凑摘要：实际 TUN 内核/版本、运行状态、配置状态；说明保存与启用独立。
3. 分组导航：基础 / DNS / UDP / 捕获范围 / Linux 高级 / 帮助。
4. 表单：每项有中文名称、一句话说明、使用说明入口；技术字段和枚举主要放在帮助中。
5. 宽窗右侧帮助；窄窗使用模态帮助抽屉。帮助目录可搜索选项、技术键与详细场景文案，支持无结果状态。
6. 底部常驻操作：修改计数、恢复本组默认、取消修改、唯一主要操作“保存并应用”。

首次打开：macOS、浅色、中文、基础组、自动路由开启，其余新增策略自动或未启用。macOS 默认隐藏严格路由和 Linux 控件；“查看其他平台选项”只读展示。Linux 导航始终可发现；不适用时提供说明。

## 字段与控件清单

下表的默认值是**原型演示基线**。正式接入必须从用户既有配置初始化；`auto` 是“不要新增覆盖”的界面哨兵值，不应无条件写成 sing-box JSON 的字面量。表中技术键是待核对的交接映射，不能替代实际内核 schema 验证。

### 基础

| 名称 / 模型 | 技术映射 | 控件与选项 | 演示默认 / 联动 |
|---|---|---|---|
| 自动路由 `autoRoute` | `auto_route` | 开关 | 开；关闭后捕获范围与 Linux 路由相关项暂不生效；已开启且缺依赖的开关仍可关闭 |
| 严格路由 `strictRoute` | `strict_route` | 开关 | 关；演示能力表仅 Windows/Linux；依赖自动路由；其他平台可只读查看 |
| 网络协议栈 `stack` | `stack` | 自动 / 用户态 gvisor / 系统 system / 混合 mixed | 自动；具体协议支持、平台差异由原生能力表核对 |
| 最大传输单元 `mtu` | `mtu` | 自动 / 1500 / 1400 / 9000 / 自定义 | 自动；自定义整数 576–65535，原型格式约束 |
| IPv6 `ipv6` | v2rayN 地址族配置意图 | 开关 | 关；控制 IPv6 接口地址、DNS 推导；保留禁用时的地址草稿 |
| ICMP 策略 `icmp` | `icmp_policy` **界面模型** | 自动 / 交给路由处理 / 拒绝接管报文 | 自动；明确提示显式策略需要原生能力校验；不是已确认的核心 JSON 键 |
| 兼容前置检查 `compatibility` | `compatibility_preflight` **界面模型** | 开关 | 关；表达协议栈/ICMP 能力预检意图；页面不探测内核 |
| 设备名称 `device` | `interface_name` | 自动 / 自定义文本 | 自动时不指定；macOS 自定义必须 `^utun\d+$`；Windows/Linux 演示限制 1–15 个字母数字或 `_ . : -` |
| IPv4 地址 `ipv4Addresses` | `address` IPv4 条目 | 可增删 CIDR 列表 | `172.18.0.1/30`；至少一条；校验前缀、地址族、重复 |
| IPv6 地址 `ipv6Addresses` | `address` IPv6 条目 | 可增删 CIDR 列表 | 草稿 `fdfe:dcba:9876::1/126`；IPv6 默认关闭，启用后校验至少一条与地址族 |
| TCP 回接地址 `loopback` | `loopback_address` | 可增删 IP 列表 | 空；仅 TCP 回接至来源；IPv6 条目依赖 IPv6 开关 |

设备名、多地址、TCP 回接放在“接口地址与 TCP 回接”折叠区。错误定位会自动展开此区。它们仍属于基础组，恢复范围与该组一致。

### DNS

| 名称 / 模型 | 技术映射 | 控件与选项 | 演示默认 / 联动 |
|---|---|---|---|
| DNS 处理方式 `dnsMode` | `dns_mode` **生成策略模型** | 自动 auto / 接管 TUN DNS hijack / 仅虚拟入口 native / 不配置 disabled | auto 保留旧行为；不影响混合端口 DNS |
| 虚拟 DNS 入口 `dnsAddresses` | `dns_address` **待核对核心映射** | 自动推导 / 自定义可增删 IP 列表 | 自动；`172.18.0.1/30 → 172.18.0.2`；IPv6 开启时另推导 `fdfe:dcba:9876::2` |

- `auto`：不新增覆盖，保留现有生成语义。
- `hijack`：表达接管 TUN DNS 的意图。
- `native`：仅处理发往虚拟 DNS 地址的请求；不会因为该模式自动接管其他 DNS。
- `disabled`：不配置或自动接管 TUN DNS；自定义入口草稿保留，但禁用、忽略校验。
- 虚拟 DNS 是 TUN 内部入口，**不是公共 DNS 上游**；页面不提供公共上游编辑。
- 自动推导从接口地址递增一个可用地址；不能推导时阻止保存并指向入口。不会臆造 /32 或 /128 中的第二个地址。
- 自定义入口不带 CIDR 前缀；必须属于已启用的接口网段；不能与接口自身地址、IPv4 网络/广播地址相同；不能重复。不同写法的同一个 IPv6 也算重复。

### UDP

| 名称 / 模型 | 技术映射 | 控件与选项 | 演示默认 / 联动 |
|---|---|---|---|
| UDP 映射 `udpMapping` | `udp_mapping` | 自动 / 与目标无关 endpoint_independent / 按地址 address_dependent / 按地址和端口 address_and_port_dependent | auto；帮助解释跨目标的映射复用差异 |
| UDP 过滤 `udpFiltering` | `udp_filtering` | 与上面相同的四个值 | auto；帮助解释允许返回数据的远端范围 |
| 空闲超时 `udpTimeout` | `udp_timeout` | 自动 / 1m / 5m / 10m / 30m / 自定义 | 自动；自定义支持正数加 ms/s/m/h；原型上限 24h |
| 最大映射数量 `udpNatMax` | `udp_nat_max` | 自动 / 4096 / 8192 / 16384 / 自定义 | 自动；自定义正整数，原型上限 1048576 |

组内与帮助都说明：NAT 参数只影响 TUN 内部状态，不代表出口支持 UDP，也不保证公网 NAT 类型改变。超时和数量上限都是原型表单约束，需父任务核对实际支持范围。

### 捕获范围与规则集

| 名称 / 模型 | 技术映射 | 控件与选项 | 演示默认 / 联动 |
|---|---|---|---|
| 接管地址 `routeAddress` | `route_address` | 可增删 IPv4/IPv6 CIDR 列表 | 空；自动路由开启后可编辑 |
| 排除地址 `routeExclude` | `route_exclude_address` | 同上 | 空；同上 |
| 接管规则集 `routeSet` | `route_address_set` | 可搜索多选，选中标签可移除 | 空；自动路由依赖 |
| 排除规则集 `routeExcludeSet` | `route_exclude_address_set` | 同上 | 空；自动路由依赖；相同规则集不能同时选入两侧 |
| 规则集库 `resources` | 独立规则集资源定义 | 添加、编辑、删除；名称、来源、格式、文件/URL | 两条明确的演示资源，见下表；删除会同步移除引用；重命名会迁移引用 |

| 示例资源 | 来源 | 格式 | 演示位置 |
|---|---|---|---|
| geoip-cn | 远程 | binary / SRS | `https://example.com/rules/geoip-cn.srs`，仅文本，不请求 |
| office-net | 本地 | source / JSON | `office-net.json`，仅名称，不读取 |

规则集对话框校验名称唯一与合法字符；远程地址必须是无嵌入凭据的 HTTP(S) URL；本地可输入路径或选文件记录名称。没有文件存在性、规则集格式内容或远程可达性验证。**完整模板只读模式下不得添加、编辑或删除。**

本组的明显提示区分：操作系统捕获范围决定“先进入 TUN 的流量”；代理分流规则决定“进入后的流量如何选择直连或代理”。恢复本组默认清空范围选择，**保留规则集库**，避免把共享资源误当作表单默认值删除。

### Linux 高级

默认仅 Linux 可编辑；macOS/Windows 隐藏，选择“查看其他平台选项”后全部只读。

| 名称 / 模型 | 技术映射 | 控件与选项 | 演示默认 / 联动 |
|---|---|---|---|
| 自动重定向 `autoRedirect` | `auto_redirect` | 开关 | 关；依赖 `auto_route` |
| 网卡范围 `interfaceMode` + `interfaceItems` | `include_interface` / `exclude_interface` | 不限制 / 仅包含 / 排除 + 可增删网卡名 | 不限制；共享互斥模式；依赖自动路由 |
| 包含 UID `uidInclude` | `include_uid` / `include_uid_range` | 可增删单值与范围 | 空；依赖自动路由 |
| 排除 UID `uidExclude` | `exclude_uid` / `exclude_uid_range` | 同上 | 空；允许与包含列表合法组合，也允许语法合法的相交范围；实际优先级由原生核对 |
| MAC 范围 `macMode` + `macItems` | `include_mac_address` / `exclude_mac_address` | 不限制 / 仅包含 / 排除 + MAC 列表 | 不限制；互斥模式；依赖自动重定向 |
| 命名空间 `netns` + `namespaceName` | `netns` | 当前 / 已有名称 / 绝对路径 | 当前；仅校验名称和路径文本，不创建、不检查存在性 |
| MPTCP 直连例外 `mptcp` | `exclude_mptcp` | 开关 | 关；依赖自动重定向和自动路由；开启时强调 MPTCP 绕过 TUN 并直连 |

UID：0–4294967294，接受 `1000`、`2000-2999` 或 `2000:2999`；范围须递增。原生转换时按单值/范围拆到对应集合，不应把 UI 文本直接写到核心配置。MAC 使用六组十六进制冒号格式；网卡名提供可输入文本，不冒充枚举到的真实网卡。

以下收在“标记、队列与路由编号”低频折叠区，默认自动，不猜测内核分配值。依赖自动重定向；自动路由失效时 `autoRedirect` 本身会产生错误，阻止保存。

| 名称 / 模型 | 技术映射（待原生 schema 核对） | 预设 / 自定义校验 |
|---|---|---|
| 输入标记 `markInput` | `auto_redirect_input_mark` | auto / 示例 0x2023 / 自定义 1–4294967295；支持十进制与 0x |
| 输出标记 `markOutput` | `auto_redirect_output_mark` | auto / 示例 0x2024 / 自定义同上 |
| 重置标记 `markReset` | `auto_redirect_reset_mark` | auto / 示例 0x2025 / 自定义同上；三个显式标记按数值比较不得重复 |
| NFQueue `nfqueue` | `auto_redirect_nfqueue` | auto / 示例 100 / 自定义 0–65535 |
| 路由表 `tableIndex` | `iproute2_table_index` | auto / 示例 2022 / 自定义 1–4294967295 |
| 路由规则 `ruleIndex` | `iproute2_rule_index` | auto / 示例 9000 / 自定义 1–4294967295 |
| 回退规则 `fallbackIndex` | `auto_redirect_iproute2_fallback_rule_index` | auto / 示例 32765 / 自定义同上；不能与显式路由规则编号数值相同 |

## 联动、校验与状态契约

| 状态 / 操作 | 交互与数据结果 |
|---|---|
| 初始已保存 | 保存和取消禁用；恢复本组在已为默认时禁用；不会启动 TUN |
| 字段修改 | 内存草稿更新；底部计数与导航修改点更新；文本在变更/失焦后校验，保存总是重新校验 |
| 调整预设为自定义 | 展示并聚焦输入框；DNS 自定义首次取当前推导值作为可编辑草稿 |
| 未启用或不适用字段 | 草稿保留；不适用项不参加当前平台校验，不能编辑；依赖未满足的非开关字段不生效 |
| 关闭依赖后仍有开启的下游开关 | 不静默清除用户选择；下游开关仍允许关闭；校验错误阻止保存 |
| 保存时有错误 | 汇总所有错误并提供可点击定位；切换正确组、展开折叠区、聚焦字段；行内错误 + `aria-invalid` |
| 应用中 | 约 900ms 纯计时模拟；锁定表单、写操作与演示环境，防止重复提交；导航和帮助可阅读 |
| 模拟成功 | 已保存快照 = 提交时草稿；清除脏状态；明确 TUN 仍关闭、配置待启用、未网络验证 |
| 模拟失败 | 已保存快照不变；草稿、错误修复和当前组保留；下次默认成功，可重试 |
| 取消修改 | 确认后恢复整个已保存快照，包括所有组与规则集资源；非只取消当前组 |
| 恢复本组默认 | 确认后只恢复当前组适用项；保留其他组、其他平台草稿和规则集库；仍需保存 |
| 模板接管 | 展示只读说明与跳转入口；字段和写操作全部禁用；查看模板为只读演示片段 |
| 语言 / 主题 / 平台变化 | 不重建数据草稿；不丢自定义值、条目、选中规则集或已保存快照 |
| 刷新 / 关闭页面 | 草稿不持久化；存在未保存修改时使用浏览器原生离开提醒；只持久化主题和语言 |

数据分层建议：`DraftTunSettings` / `SavedTunSettings` / `RuntimeTunSnapshot` / `CapabilityContext` / `DemoContext`。原生实现应将最后一个完全移除。草稿与运行态不可共享同一可变对象。

`window.TunPrototype` 只供离线测试纯模型与生成内容；不是给生产 WebView 的桥接 API。不得把原型的 `save()` 直接当作真实应用逻辑。

## 帮助契约

35 个选项均有一句话说明与独立“使用说明”。每份详细帮助固定包含：用途、默认值、各选项区别、适用场景、平台/版本/依赖、修改影响、示例、故障排查。

技术枚举和值放在帮助内；DNS 与 UDP 使用中文选项含义，详细帮助显示完整枚举。目录在当前语言帮助全文与中英选项名上搜索，包含空结果文案；无联网补充。宽窗切换帮助不改变草稿，窄窗关闭抽屉返回原帮助触发位置。

页面为 `100dvh` 纵向 flex，顶栏/标题/底部操作不收缩；中间区域 `min-height:0`。表单和宽窗帮助各自纵向滚动；固定底部不盖住表单末尾。控件和正文都 `min-width:0`，长地址可换行，输入宽度不超容器；不依赖页面横向裁切。

普通按钮、下拉和输入高度至少 44px；开关可见轨道 44×28px，其外扩命中区至少 44px 高；多选移除键可见较小，但在触控目标修正后达到 44px。对话框宽 500px，受视口左右 16px 限制；帮助抽屉宽 400px，最多视口宽减 24px。

设计适配 360 / 390 / 430 / 600 / 768 / 820 / 1024 / 1366 / 1440 / 1920px。交付验证包括这些宽度下网格剩余宽度和控件约束的静态推算；没有宣称浏览器逐尺寸像素验收。

## 视觉与无障碍

- 精确沿用提供的 Primer `:root` 合约；白底/深海军蓝、1px 边框、6px 圆角、14px 正文、24px 页面标题、16px 分区标题。系统字体与等宽技术字体，字重仅 400/600。
- 唯一实心主操作为“保存并应用”；导航与开关采用中性状态。绿/黄褐/红分别承载模拟成功/待启用/错误，同时显示文字。
- 中英系统字，无字体下载；图标为内联功能性线条 SVG；没有装饰图片或外部图片。
- Tab/Shift+Tab 访问控件；原生 select 的方向键/Enter；Space 切换开关和多选；导航方向键、Home/End 切换分组。
- `⌘/Ctrl+S` 保存；`F1` 进入离线帮助并聚焦搜索。原生对话框焦点圈定、Esc 关闭；多选展开区支持 Esc 收起并回到摘要。
- 字段通过 label 或 aria 名称关联；错误使用 `aria-invalid`、说明关联与汇总定位；状态提示 `aria-live=polite`；应用中 `aria-busy`。
- 焦点圈在浅深主题都有独立可见轮廓；悬停保留文字颜色并改变背景/边框；禁用保留说明，帮助仍可访问。
- `prefers-reduced-motion` 禁用过渡/按压位移；不移除状态转换所需的模拟等待。
- `data-od-id` 为区域、字段、主要操作和重复条目提供可检查标识；不存在历史评论 UUID 迁移问题。

## Avalonia 移植建议与待确认事项

1. 用 `Grid` 实现三栏与窄窗两层布局；表单/帮助分别 `ScrollViewer`，操作栏作为独立底行。窄窗帮助使用原生侧栏/对话框，不嵌 HTML。
2. 用 `ComboBox`、`ToggleSwitch`、可编辑 `ItemsControl`、原生多选列表与规则集对话框实现对应控件；只读平台项与模板状态同时校验命令的 CanExecute。
3. 默认值由父任务从现有 v2rayN 配置载入。原型中的开启/关闭与示例地址不可覆盖用户既有配置。自动值按“省略新增覆盖/保留旧行为”解析。
4. 保存前建立与**实际 TUN 内核**匹配的能力表；不能借用主代理内核版本。所有新增字段、预设范围、ICMP 策略、DNS 生成策略和高级键名均需通过匹配版本的真实 schema 核对。本项目因禁止内核与网络访问，没有声称完成这一步。
5. 特别核对 `icmp_policy`、`compatibility_preflight`、`dns_mode`、`dns_address` 和 NFQueue/mark 映射；前四个明确是 UI/生成策略交接意图，不能直接序列化为假定已支持的核心字段。确认严格路由、协议栈与 loopback 在各平台的实际能力。
6. UID 包含/排除交集的最终优先级需原生核对；如核心无法表达，提供显式错误，不静默改写。也需要确认系统保留路由表号、权限、设备名占用、命名空间与规则集内容，这些不是纯格式校验。
7. 原生应用需要按现有配置生成/应用路径接入，分别处理持久化成功与应用失败；保持运行快照，日志注明真实变更原因。有效配置未改变时保留现有连接，不做无必要重载。
8. 该页保存不得打开主界面 TUN 开关。TUN 关闭时保存设置并维持“待启用”；TUN 已运行时真实重载、失败回滚、权限提示和连接影响由父任务完成并验证。
