# TUN 原稿与原生界面复查

日期：2026-10-28 至 2026-10-29。分支：`feature/tun-design-fidelity`，基于 `a62bd22b`。下述截图与本地包验证在提交前完成；发布版本随后由 release 分支的预览标签触发。

原稿仍为本目录的 `index.html` 与 `design-handoff.md`。本轮只修正原生实现，没有反向修改原稿。此前通用的竖排边框按钮、通用列表编辑器、重复的设置导航和控件间距造成了明显偏差。

## 本次还原

- 六项带编号的分组导航；未选中项无边框，选中项有浅底和细边框。
- 固定内容上限、导航/表单/帮助三列、四格运行摘要、底部固定操作栏；TUN 页收起重复的设置目录，并保留返回入口。
- 逐项标题、短说明、下划线帮助入口、44px 控件、6px 圆角及原稿深浅色；去掉原生主题附加的滚动条箭头。
- DNS 使用“自动推导/自定义”选择器、接口到入口的推导卡片，支持自定义地址原位增删；切换模式会即时更新解释。
- 地址、网卡/UID/MAC 范围和规则集采用对应的组合编辑器，保留真实配置读写和平台限制。
- 完整八节离线说明、可搜索结果列表、宽窗帮助栏，以及带遮罩、标题栏和焦点返回的窄窗抽屉。
- 修改点、修改计数、保存结果和模板只读状态；修正关闭父开关后，下游已开启开关无法关闭的问题。
- 已为默认值时禁用恢复按钮；恢复与取消先确认。恢复捕获范围只清空范围选择，保留共享规则集来源。

原稿的模拟环境、假内核版本和假运行状态未进入产品。真实默认值、兼容前置与 ICMP 的既有含义保留，文案以实际核心配置为准。
