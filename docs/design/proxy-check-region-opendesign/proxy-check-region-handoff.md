# 代理检查：地域独立比较

## 交付与范围

直接打开 [proxy-check-region.html](proxy-check-region.html)。自包含 HTML/CSS/JS 与内嵌 PNG，无依赖、无网络请求，不持久化配置；刷新恢复演示。仅新增本页和本文，不改已有原型及客户端，不提交或推送。

参考项目 `proxy-check-collapse.html` 与指定 `ProxyCheckView.axaml`。当前 AXAML 已含分类/证据双层 Expander、独立路径能力说明、检查选项、实际出口及预期比较列；新增地域内容延续这些区域，不改变原列的 IP 比较含义。

## 评审入口

- 默认完成含失败，预展开 TCP/TLS、DNS、UDP，便于查看逐 IP 地域；其他分类及证据可独立展开。
- “检查选项”打开可搜索多选，含新加坡、日本、香港、美国；默认前三项。支持名称/英文/代码搜索，隐藏的已选项保留。
- 顶部演示切换：完成含失败、地域查询中、地域未知、多 IP 出口、检查中。“查询中”可手动模拟完成。
- 新完整检查重置全部分类/证据/能力说明为折叠；搜索/筛选不自动展开，重试保留展开状态。

## 数据与判定契约

地域为独立附加数据，不进入 `isFailure`、`needsAttention`、进度、通信通过或 IP/CIDR 匹配计算。没有 IP/地域联合通过模式，也不新增地域综合成功指标。

| 数据 | 含义 |
|---|---|
| savedRegions / configVersion | 已保存的下轮配置；多选 ISO 地区代码，OR 关系 |
| draftRegions | 对话框草稿；关闭/取消丢弃，清除可保存为空 |
| reportRegions / reportVersion | 本次完整检查捕获的地域预期，独立复制，不引用可变配置 |
| result.geography.expected | 每个结果沿用报告快照；重试仍使用该快照 |
| geography.entries[] | 每 IP 独立的 ip、country、city、查询状态、provider、queriedAt |

保存不重算旧报告；新完整检查才复制已保存配置。重试更新失败项证据时仍使用原报告预期。原型“保存”仅更新内存，不能宣称已写入客户端配置。

地域判定：无选择显示“未配置地域”；有选择但查询中/未知均不匹配；已知代码在 OR 集合内为“地域匹配”，否则“地域不匹配”。查询状态单独保留，即使无预期也能显示“查询中/地域未知”。递归 DNS 固定标“解析器地域·不比较”，不参与客户端地域比较；系统能力项和无有效出口项不查询、不伪造国旗。

原 IP 比较与地域可相反：native HTTPS 的 IP 符合原预期但美国地域不匹配；SOCKS5 STUN 的 IP 不匹配但日本地域匹配。两者不会互相覆盖。多 IP 示例位于无 IP 预期的 native DNS/UDP，逐一显示美国、日本和未知 IPv6，原 IP 结果仍为未配置。

## 展示与证据边界

实际出口单元格按 IP 渲染独立块：等宽 IP → 小国旗与国家/地区/城市 → 轻量地域状态。每张旗帜只属于同块 IP。未知与查询中使用中性问号图标。国旗来自用户授权的 `v2rayN.Desktop/Assets/Flags/{sg,jp,hk,us}.png`，已转为内嵌 data URI；保留原图宽高比（前三者 100×67，美国 100×53），不依赖远程服务。

详情新增第三方数据库名称、版本与逐 IP 查询时间。地域是第三方数据库估计，不是服务端签名事实、不保证物理位置。所有 RFC 文档 IP、城市映射、来源名称和时间均为虚构模拟，不暗示这些文档地址存在真实地理归属。原服务端协议证据与数据库地域注释分开显示。

## Avalonia 交接建议

保留现有 Expander 和 `ProxyCheckGrid`，实际出口列改为 `ItemsControl`，每 IP 子项用 `StackPanel` + 等宽 `SelectableTextBlock` + `Image`/中性图标 + 独立地域标签。预期比较列继续绑定原 IP/CIDR 结果；不要把地域状态绑定 `IsFailed`/`HasAttention`。

检查选项中用搜索 `TextBox`、复选列表与选中摘要实现多选；报告捕获不可变地区集合。地域查询返回以会话 ID + 结果 ID + IP 关联，拒绝旧会话回调，不能按结果行索引合并国旗。以上仅概念映射，未读取 ViewModel 或修改业务逻辑。

## 可访问性与验证

沿用 Primer tokens、14/12px、系统字体、6px 圆角、浅深主题和中英文。原生按钮支持 Enter/Space，复选框支持 Space，dialog 支持 Tab 焦点约束与 Esc；关闭/保存回到检查选项按钮，多选更新后保留复选框焦点。窄窗 <=1260px 使用两列结果卡片，<=650px 单列；选项正文可滚动、操作条独立可见。尊重减弱动态效果。

12 项项目内离线检查通过：OR/相反结果、搜索保留、保存快照、重试快照、完整检查捕获与折叠、查询中/未知、统计隔离、多 IP 配对、解析器/能力边界、取消与筛选、双语主题场景、内嵌资源与响应式规则。追加检查覆盖多选焦点与关闭/保存焦点返回。

已真实渲染默认中文浅色展开态，核对标题、原比较列与逐 IP 国旗/地域状态，无可见重叠。英文/深色及窄窗进行状态/内容与断点代码检查，未逐组合进行真实浏览器视觉或键盘自动化验收。未访问真实代理/服务器或运行客户端测试。
