# 地域独立匹配与逐 IP 国旗：实现验收

2026-10-28。先使用本机 OpenDesign 的 Local Codex 生成 `proxy-check-region.html`，核对其结果展示与地域多选预览后实现 Avalonia 界面。本目录保留设计原稿及交接说明。

## 已确认语义

- 用户选择“地域单独显示匹配结果，不影响现有 IP 判定”。地域结果不写入 `State`、`Connectivity` 或 `EgressState`，也不影响通过、失败、需关注计数或失败重试资格。
- 预期粒度为国家/地区，支持中文名称、英文名称与两字母代码搜索、多选及清除；多个预期为 OR。每个观测 IP 独立显示自己的匹配结果。
- 无选择显示未配置地域；查询中和未知不算匹配；递归 DNS 只展示解析器地域，不与客户端地域预期比较；系统配置能力项不适用。

## 实现与配置

- `ProxyCheckOptions.ExpectedCountryCodes` 默认空列表，旧配置保持原行为。按现有检查选项生命周期，在开始完整检查时持久化选择并捕获本轮快照；界面文案明确说明此行为。现有“完成”按钮关闭选项窗口，不引入原型中的独立保存/取消草稿流程。
- 每行保存 `ExpectedCountryCodes` 快照。修改选择不重算旧结果，重试沿用原报告的地域预期，同时保留用户为下一轮完整检查选择的配置。浏览器 WebRTC 新报告也捕获独立地域预期。
- 报告添加独立的 `RegionComparison`；不改变版本和已有 IP/签名证据字段。第三方地域、来源和查询时间仍与签名观测分离。
- 实际出口改为逐 IP 块：等宽地址、本地国旗与地域、独立地域状态。匹配使用绿色，不匹配使用提示色；未知采用中性图标，不猜测旗帜。国旗复用软件内置位图并加细边框，支持浅深主题，不增加远程国旗服务。
- 既有地域异步查询仍使用结果对象和地址核对，晚到或旧会话回调不会更新新结果。分类与证据折叠行为保持。

## 验证

- Local Codex 原型的 12 项离线检查及焦点补检通过；通过本地设计服务预览核对了逐 IP 展示和地域多选。
- Release 构建成功。编译器仍有现有 ReactiveAttribute 类型冲突警告。
- 57 项相关测试通过：代理检查/展示/地域比较 32 项、地域查询 17 项、观察端矩阵 6 项、WebRTC 2 项。
- 实际 Avalonia 控件通过 Headless + Skia 渲染验收，四组各 47 项断言及 16 张截图：中文浅色 1440px、英文浅色 1440px、中文深色 700px、英文深色 700px。
- 验收包含本地国旗确实加载、多 IP 与地域对应、未知图标、地域不影响 IP 判定及计数、多选搜索与清除、旧行快照不变、分类键盘展开及窄窗布局。
- 截图与 `manifest.json` 位于工作区 `artifacts/proxy-check-region-20261028/`。这些是隔离演示数据，不是实际节点网络检测结果。
