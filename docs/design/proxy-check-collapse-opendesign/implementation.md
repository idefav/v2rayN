# 路径能力说明与分类折叠：实现验收

2026-10-28，先由本机 OpenDesign 的 Local Codex 在现有 Primer 设计项目生成原型，再检查预览并实现 Avalonia 界面。设计原稿保存在本目录，全部示例为模拟数据。

## 实现

- 普通 HTTP CONNECT 的 UDP、STUN/UDP、DNS/UDP、QUIC/HTTP3 固定限制使用共享定义，在任务生成时排除。公共模式移除 `http-no-udp`，受控模式移除对应 7 个固定组合，不进入结果、统计、导出或重试；底层仍保留拒绝与禁止直连回退的防御判断。
- 所有结果分类及独立路径能力说明默认折叠。分类标题显示匹配数量、完整分类的完成进度与需关注数量。整行标题可点击，键盘 Space 可展开；行级证据保持独立。
- 实时更新、搜索、筛选和重试保留分类及行级展开状态；开始完整检查时清空状态。动态 UDP 不支持或失败仍正常显示。
- 实际软件按检查开始时快照标注“普通套接字（TUN 关闭）”或“系统网络栈（TUN 开启）”，不把配置开启表述为已证明接管。设计稿的 native 演示措辞以此实现说明为准。
- 多个预期 IP/CIDR 的原有任选其一语义保持，输入提示明确使用英文逗号。保留现有地域信息改动，地域信息与探测证据继续分离。
- 报告格式兼容；旧基线中被移除的任务不会与新任务匹配。静态能力说明属于界面元数据。

## 验证

- Local Codex 原型的 12 项离线交互检查通过；通过本地设计服务预览检查默认折叠、UDP 分类展开及能力说明独立展开。
- Release 构建通过。现有 Debug 开发工具引用错误不属于本次修改；Release 构建仍可能报告现有 ReactiveAttribute 类型冲突警告。
- `ProxyCheckTests` 与 `ProxyCheckPresentationTests` 共 26 项通过；`ObserverTests` 共 6 项通过。
- 实际 Avalonia 控件以 Headless + Skia 渲染，四组各 39 项断言、14 张截图：中文浅色 1100px、英文浅色 1100px、中文深色 700px、英文深色 700px。包括默认折叠、键盘展开、能力说明独立展开、进度、窄窗字段和列标题布局。
- 截图及各组 `manifest.json` 保存于工作区 `artifacts/proxy-check-collapse-20261028/`。截图使用隔离演示数据，不代表真实网络验证。

界面审阅只使用测试进程自己的配置，禁止系统代理修改且不启动内核。没有发布、安装或替换客户端，没有改变当前代理与 TUN 设置。
