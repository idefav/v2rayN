## 布局映射

指定 AXAML 目前以 `ResultGroups` 渲染分类：静态分类标题后接行列表，行本身使用 `Expander` 展示证据。本次建议将**分类标题及其行列表包进外层 Expander**，保留行级 Expander，避免重写结果布局。

| 区域 | Avalonia 建议 | 行为 |
|---|---|---|
| 六类结果 | 外层 `Expander` + `ItemsControl` | 默认收起，整行标题点击；名称、总数、完成数/总数、需关注数始终可见 |
| 单行证据 | 原行级 `Expander` | 独立展开；父分类收起后仍记住状态 |
| 路径能力说明 | 独立 `Expander` | 默认收起，放在结果集合外，不产生结果行 |
| 搜索与筛选 | 原搜索框及结果过滤器 | 只改变可见结果，不改变展开状态或分类统计基数 |

分类建议增加概念属性 `IsExpanded`、`CompletedCount`、`TotalCount`、`AttentionCount`。这些是交接建议，不表示已核实当前 ViewModel 存在同名属性。分类和证据分别以稳定 ID 保存展开状态；不要因过滤重建集合而丢失状态。标题使用一个可聚焦控件，避免嵌套按钮。

## 状态契约

| 触发 | 分类 / 证据 / 能力说明 | 结果与进度 |
|---|---|---|
| 首次打开 | 全部收起 | 默认完成且含失败的演示 |
| 新完整检查 | 全部重置收起 | 固定本次节点及 TUN 快照，重新执行模拟 |
| 重试失败项 | 保持当前展开状态 | 仅重试通信失败及出口不匹配项；不匹配不会伪造恢复 |
| 搜索、筛选 | 保持当前展开状态，不自动展开 | 分类统计使用完整分类；另标匹配数量 |
| 切换语言、主题、演示状态 | 保持当前展开状态 | 中文/英文；浅色/深色；检查中/完成含失败 |
| 更改 TUN 演示 | 按新完整检查重置 | 捕获新快照，不修改系统 |
| 取消 | 保持当前展开状态 | 未执行项记为已取消，不计入已完成，晚到回调无效 |

完成进度与通过率分离；“需关注”包含通信失败、出口不匹配、缺少预期和不支持等演示项。通信通过与出口匹配分别呈现。无预期显示未配置；普通 TCP 和设置能力项不捏造出口；系统 DNS 递归解析器观察独立标明，不用于客户端出口比较；IPv6 不支持明确展示。

## 路径能力说明的边界

16 项结果包含 2 项接管状态与 14 项探测演示。另有 4 条固定说明：普通 HTTP CONNECT 不承载 UDP、STUN/UDP、DNS/UDP、QUIC/HTTP3。它们标明**未执行、没有样本、不计入检测统计**，不使用“跳过结果”占据结果行。此限制针对普通 TCP CONNECT，不推及 CONNECT-UDP、MASQUE 或其他扩展。HTTP CONNECT 上的 HTTPS/TLS 探测仍保留。

SOCKS5 与 native 路径保留真实探测类型的模拟项目，包括 DNS/UDP、STUN/UDP 和 HTTP3。native 标签取自**检查快照**：TUN 开启为“native · TUN 接管”，关闭为“native · 直连（TUN 关闭）”；不根据展开时的实时开关改写旧报告。
